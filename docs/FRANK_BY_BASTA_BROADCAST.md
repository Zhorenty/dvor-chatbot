# Рассылка: DVOR × FRANK BY BASTA

Готовый HTML-текст для админ-рассылки бота (`Рассылка` → пользователи).

## Как работает ссылка

- Deep link: `https://t.me/dvor_chatbot?start=frank`
- Открывает промо забега и кнопку `✍️ Записаться` на ту же тренировку из расписания.
- Превью ссылок в рассылке отключено (`disable_web_page_preview`).
