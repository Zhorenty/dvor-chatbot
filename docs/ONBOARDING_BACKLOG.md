# Онбординг: бэклог каркаса с Miro

Итерации, чтобы закрыть каркас «Онбординг» с доски, не ломая живой квиз и [`VOICE.md`](VOICE.md).

Источники каркаса: доска Miro «Онбординг каркас», разбор 21.08.2026. Copy со стикеров в бота не переносить.

## Решения команды (24.08.2026)

1. **Календарь города** — как правило всегда так (сила / бокс / забег), но бывают нюансы. В боте показываем ближайшие слоты этих типов **из Sheets**, не хардкодим «среда Даша».
2. **Outdoor** — пока две кнопки: тренировки / направление outdoor.
3. **Ролики** — админ обновляет через `🧰 Инструменты` → `🎥 Онбординг-видео`: присылает видео или кружок, бот хранит `file_id` в SQLite.
4. **Отмены (все брони, не стартовый бонус):** 7д 18/102, 30д 63/428 ≈ 15%. Отдельное видео «что взять» не снимаем: хватает колонки `заметки`.

## Уже закрыто

- Квиз: цель → опыт → формат → запись. Цель №1 — слот, не чат.
- `/start` сразу задаёт вопрос. `?start=book` открывает запись.
- Чат — вторая дверь, представляться не обязательно.
- **1.1** Счётчик отмен стартового бонуса в админке и `АНАЛИТИКА`. По общим броням ~15% — видео «что взять» не делаем.
- **1.2 / 5.1** На карте клуба (городской трек) — ближайшие силовая / бокс / забег из таблицы. Нет слота этого типа — молчим, не врём про день недели.
- **1.3** Две кнопки формата. Четыре outdoor-ярлыка не вводим.
- **2.1** Рассылка `🥾 Outdoor+`.
- **2.2** `заметки` слота после записи на тренировку.
- **2.3** Drip day 1/2 называет ближайший слот.
- **3.1 / 3.2 / 4.1 / 4.2** Транспорт `sendVideo` / `sendVideoNote`. Слоты: **Площадка** (после первой записи) и **Пришёл один** (карта клуба). Пока слот пустой — человек его не видит.

## Принципы

1. Бот — польза: слот, афиша, что взять. Не каскад «кто мы».
2. Медиа — поверх шагов квиза, не вместо них. Не на `/start` вместо вопроса.
3. Источник слотов — Google Sheets.
4. VOICE — контракт текстов.

## Парковка

- Вся доска целиком, каскад 24–48 часов на каждый формат.
- Выкинуть квиз ради кружков.
- Первый CTA = чат.
- light / middle / hard, «DVOR — большая семья», обязательная визитка.
- Дубль ОС внутри воронки.
- Хардкод «среда Даша / четверг Давид», если в таблице на этой неделе иначе.
