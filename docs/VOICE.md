# Голос DVOR

Как писать тексты клуба: посты в группу, рассылки, шаблоны бота, поздравления, онбординг.

Источник правды для агентов: этот файл. Секция Voice and Copy в `AGENTS.md` — короткий указатель сюда.
Если просят «составь текст» / «напиши пост» / правят copy — сначала свериться сюда.
Существующие формулировки в `message_templates` не «выравнивать» под эталон вехи без отдельной задачи на copy.

## Кто мы

DVOR — спортивное объединение, не сеть залов и не воронка продаж.
Люди ходят вместе: бег, сила, бокс, походы, трейлы. Бренд пишем `DVOR`.
Текст звучит как свой человек из команды, не как пресс-служба.

Обращение:

- личка и один человек (велком по имени) — «ты»;
- группа как зал — «вы»;
- в одном тексте не прыгать.

## Принципы

1. **Смысл раньше энергии.** Сначала факт и что он значит для людей, потом эмоция.
2. **Конкретика вместо абстракций.** Не «сообщество единомышленников», а утренние забеги, силовые, бокс, походы, слоты, площадка — и только то, о чём этот текст.
3. **Вместе, не поодиночке.** Команда, компания, «свой» — без пафоса «семья» и «лучшая в мире».
4. **Коротко.** Короткие предложения, абзацы по 1–3 строки, воздух между блоками.
5. **Без продажи, если это не цель.** Поздравление, велком, веха — без FOMO и промокодов. CTA только когда сообщение про действие.
6. **Все свои.** Новичок, постоянный, тот кто приводит друзей, тот кто молча читает и приходит на тренировки — всем есть место.

Не копировать ритм поста про 1000 человек на любой повод.

## Карта жанров

Сначала выбрать строку. Скелет вехи — только для community.

| Жанр | Цель | CTA | Длина | Закрытие |
| --- | --- | --- | --- | --- |
| Веха / спасибо / поздравление | смысл момента | нет | 5–7 коротких абзацев, ~500–800 знаков | `До встречи на площадке. DVOR 🤝` (поход/трейл: на маршруте / на трейле) |
| Велком в группе | узнать человека + вход в бота | да, Start | 3–5 строк | без церемонии, ссылка |
| Афиша / слоты / «сегодня тренировка» | факт + запись | да, один | заголовок + 3–5 строк фактов + CTA | ссылка в бота |
| Рефералка / оплата | действие | да | коротко, шаги 1-2-3 | без истории клуба |
| Личка бота | статус | один следующий шаг | 1–4 строки | без подписи клуба |
| Онбординг | один вопрос или один шаг | нет, пока не запись | 1–3 предложения | без карты всего клуба |
| Админка | ясность | нет тепла | суше некуда | — |

## Форма

Community (веха, спасибо, поздравление):

- заголовок: один эмодзи-якорь + факт (`🔥 DVOR — нас ровно 1000`);
- дальше: что случилось → что это значит живым языком → благодарность по ролям → взгляд вперёд без давления → физическое закрытие;
- этот скелет не переносить в промо, велком, запись и онбординг.

Остальное:

- экшен-пост: заголовок → факты (когда, где, места) → один CTA;
- личка: факт → статус → что делать дальше;
- онбординг: спокойно, без разжёвывания клуба сразу;
- админка: ясно и сухо.

Telegram:

- HTML, `<b>` только на заголовок и 1–2 якоря, не на весь абзац, без Markdown;
- пользовательские строки (имя, название тренировки, комментарий) — экранировать;
- эмодзи — якоря, не конфетти: community 1 в заголовке + опционально `🤝` в конце (`🔥 🤝 🏃 💪`); в карточках бота — подписи к полям (`🕒 📍 💳`);
- не открывать с «Друзья,» / «Команда DVOR сообщает».

## Эталоны

Тон и ритм, на которые равняться. Не пересказывать эталон вехи, подставляя другое число или повод.
Не вставлять «это не просто цифра» и полный список «забеги, силовые, бокс, походы, трейлы», если текст о другом.

### Веха / community

```
🔥 DVOR — нас ровно 1000

Сегодня в группе ровно тысяча человек.

Это не просто цифра. Это утренние забеги, силовые, бокс, походы, трейлы и куча людей, которые выбирают двигаться вместе, а не поодиночке.

Спасибо, что вы здесь: кто только заглянул, кто уже свой, кто тащит друзей и кто просто молча читает и приходит на тренировки.

Тысяча — красивая отметка. Дальше — ещё больше километров, подходов и совместных выездов.

До встречи на площадке. DVOR 🤝
```

### Велком в группе

```
Привет, Имя 🏃
Добро пожаловать в DVOR.

В боте — расписание, запись и подарок за старт.
Открой личку и нажми Start.
```

### Афиша / слоты

```
🔥 Завтра утренний забег

Сб, 18.08, 08:00 · площадка
Места ещё есть.

Запись в боте, в пару тапов 👇
```

### Личка бота

```
Отлично, записал тебя.
Статус: ждём оплату.
Дальше: переведи и пришли чек в этот чат.
```

Примеры статуса: «Отлично, записал тебя», «Ты уже записан 👌», «Не удалось записаться: свободных мест больше нет».

## Словарь

**Можно:** слот, площадка, запись, чек, забег, силовая, бокс, поход, трейл, команда, свой, бот, рефералка, `Start`, `PRO`.

**Осторожно — не размножать:** движ, кайф / кайфовее. «Успей» — только про конкретный слот, не про «шанс».

**Нельзя:** дорогие друзья, от лица команды, администрация, комьюнити, уникальное сообщество, не упусти шанс, эксклюзив, семья, лучшие в мире, стены `!!!`, английский сленг кроме продуктовых слов.

Не повторять каталог активностей «для атмосферы». Только то, о чём пост.
Пол: нейтрально («когда будет удобно», «когда решишь»), не «когда будешь готов».
Если просят ещё вариант — сменить ритм, не синонимы того же абзаца.

## Срочность

- Веха, велком, спасибо, отзыв — без «успей» и «не упусти».
- Можно в экшен-постах: «мест 3 из 20», «места разбирают быстро», «запись в боте».
- Нельзя: «не упусти шанс», «только сегодня», «стань частью истории», таймер ради драмы.

## Кто говорит и что можно утверждать

- Группа: голос клуба, не «я, бот».
- Личка: «я» только про действие бота («записал», «отправил чек»). Не «мы, администрация».
- Не выдумывать даты, тренеров, цены, адрес, число людей, правила отмены. Нет в запросе — не ставить.
- Число как дали, без пафосного округления («почти тысяча героев»).

## Перед отправкой

1. Жанр выбран. Скелет вехи — только если это веха.
2. Факт первый. Ничего не выдумано.
3. «Ты» / «вы» не смешаны.
4. CTA только если сообщение про действие, и он один.
5. Длина в бюджете. Нет простыни и списка всех активностей «для атмосферы».
6. Нет слов из «Нельзя» и нет подписи «администрация».
